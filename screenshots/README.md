# Screenshots

Hướng dẫn chụp màn hình giao diện ứng dụng khi demo:
1. Chạy backend (`cd backend && npm start`) và frontend (`cd frontend && npm run dev`).
2. Mở http://localhost:5174, chụp các màn hình: trang chủ tìm kiếm, chi tiết khách sạn, checkout, đặt phòng của tôi, kênh đối tác, quản trị sàn.
3. Lưu ảnh PNG vào thư mục này với tên `01-home.png`, `02-hotel-detail.png`, ...
